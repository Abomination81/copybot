OPERATOR CONTROLSGUIDE ONLY
↗Sizing & allocationsSet your exposure, not someone else's.

Percentage, fixed-share, and fixed-dollar sizing use the existing engine. Set per-lane caps and choose compounding intentionally. Minimum-order rules and fills can change the resulting share ratio.

⇄Entry & exit policyCopying is not a promise of identical fills.

Configure taker or hybrid behavior, buy/sell slippage, and maker handling. The current runtime default may flatten on the leader's first sell. Review that setting before you expect proportional trims.

ⅡArmed, halt buys, offThree states. Different consequences.

Armed permits configured execution. Halt buys stops entries while allowing the exit path. Off disarms the lane. Stopping the process does not liquidate holdings or prove venue orders were canceled.

◷Recovery & accountabilityPersistent state is part of the system.

Keep the ledger, pending execution, and operator intent together. A restart is not a reset. Existing arm intent may return on startup; inspect unresolved outcomes before resuming.

Your machine.

Linux, stable Rust, Python 3.11+, and your own compatible wallet and feeds. The repository is private while this package is being prepared.

01 / BUILD THE ENGINE
git clone https://github.com/Abomination81/copybot.git
cd copybot
cargo build --locked --release \
  --manifest-path hot/Cargo.toml --bin copybot-hot

Requires private-repository access. Building never starts or arms the bot.
